# La Haus

> La Haus is a Latin American proptech company (founded 2017, Medellín/Bogotá, Colombia) that runs
> the residential real-estate marketplaces lahaus.com (Colombia) and lahaus.mx (Mexico) plus an
> in-house brokerage. It lists de-duplicated, verified new-construction and resale housing from
> vetted developers, adds mortgage and down-payment simulators and buyer guides, and walks buyers
> through negotiation and closing at no cost to the buyer.

## Important: no public API

La Haus publishes **no public API, developer portal, API documentation, OpenAPI/AsyncAPI/GraphQL
contract, SDK, MCP server, agent card or llms.txt**. Verified 2026-08-04:

- `api.lahaus.com` is a private AWS API Gateway. Every anonymous request — root, `/openapi.json`,
  `/swagger.json`, `/graphql`, `/api-docs`, `/.well-known/*` — returns `403 MissingAuthenticationToken`.
- The consumer sites' `/api/*` paths are `Disallow`ed in `robots.txt` and return 404 to anonymous GETs.
- No `/.well-known/` document is served on any host (no `security.txt`, no OIDC/OAuth discovery,
  no `api-catalog`, no `ai-plugin.json`, no `agent-card.json`, no `agent.json`).
- No `developer.`/`developers.`/`docs.`/`status.` subdomain resolves in DNS.
- Portal/partner syndication runs through access-controlled marketing feed integrations
  (`/marketing_integrations/trovit*`, HTTP 403).

Do not attempt to call an "La Haus API" — there is no public one to call. Property data must be
obtained through the public website or a commercial agreement with the company.
